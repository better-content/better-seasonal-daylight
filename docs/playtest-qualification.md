## Primary gameplay promise and acquisition

The mod's bounded, player-visible purpose is **one server-authoritative Overworld sky clock** replacing Simple Day Length Extender, not new content. With defaults, each sunrise-to-sunrise cycle lasts 50,000 simulation ticks at 20 TPS; daylight shares follow Serene Seasons' actual northern annual phase (equinox 65% / 32,500 day ticks, summer about 74.44% / 37,222 day ticks, winter 5/9 ≈ 55.56% / 27,778 day ticks). Spring and autumn interpolate smoothly. The 5/9 fraction is a minimum, rounded upward in ticks even for custom settings below the floor; deliberately setting amplitude to zero holds a constant day at or above that minimum. Day and night exchange time without changing the 50,000-tick total. `SeasonCurve`, `ClockAccumulator`, `SeasonAdapter`, `SeasonalDaylightRuntime`, the dayTime mixins and `ClientClock` implement the source-side intent. This mod must not change gameTime/TPS or the Serene Seasons logical calendar (`day_duration` stays 24,000). The clock continues with no players; there is no first-player wait. The Overworld clock respects `doDaylightCycle=false`, /time changes and sleep, and is persisted as a bounded phase (`ClockSavedData`). Other dimensions are not clock targets. This is a source contract; actual client appearance, server correctness and staged pack behavior still require native evidence.
